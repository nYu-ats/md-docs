## How to start develop

1. Attach to running container on Visaul Studio Code
1. Install libraries from Pipfile

   ```bash
   cd $APP_PATH/app
   go mod
   ```

1. Start fastapi server
   ```bash
   go run main.go
   ```
   You can use api on http://localhost:8088.
